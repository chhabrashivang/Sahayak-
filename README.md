# Sahayak - Bridging the Awareness Gap for Welfare Schemes

## Overview

In India, millions of people miss out on life-changing government schemes, subsidies, and aid programs simply because they are unaware of their existence. Despite having policies that provide free or subsidized food, education, healthcare, and financial assistance, these benefits remain underutilized. People struggle with poverty, debt, and hunger while the solutions they qualify for go unnoticed.

Sahayak is an AI-powered platform designed to bridge this gap. By allowing users to enter basic details such as location, income, financial obligations, and personal challenges, Sahayak instantly identifies and recommends the government schemes, NGO initiatives, and policies they are eligible for. This ensures that no one is left behind due to lack of awareness.

## Features

- **Personalized Assistance**: Users enter key details, and Sahayak matches them with relevant welfare schemes.
- **Automated Eligibility Check**: AI-driven system ensures users only see programs they qualify for.
- **Comprehensive Scheme Database**: Access to verified government and NGO assistance programs.
- **Easy Navigation & Application**: Intuitive dashboard to explore and apply for schemes seamlessly.
- **Bridging the Awareness Gap**: Empowers underprivileged communities by unlocking life-changing opportunities.

## Technology Stack

- **Frontend**: React.js with Tailwind CSS for a responsive and clean UI.
- **Backend**: Node.js with Express.js for handling user data and scheme recommendations.
- **Database**: PostgreSQL for structured storage of schemes and user profiles.
- **AI Integration**: Machine learning-based recommendation system to provide personalized scheme suggestions.
- **Hosting & Deployment**: Vercel/Netlify for frontend and AWS/Firebase for backend services.

## Development Roadmap

1. **Research & Data Collection**: Gather information on all relevant government and NGO schemes.
2. **Prototype UI Development**: Design wireframes and develop the initial user interface.
3. **Backend API Development**: Implement a database and API to fetch schemes based on user details.
4. **AI/ML Integration**: Develop a recommendation system to suggest the best-matching schemes.
5. **Testing & Deployment**: Conduct beta testing and deploy for public access.
